🏥 Health Center Management

A fully professional patient services management system for Odoo 18.

🔐 Security

✅ Passwords hashed using bcrypt (werkzeug.security) — no plain text storage
✅ Record-level rules (ir.rule) — patients see only their own data
✅ Minimal use of sudo() — only where strictly necessary
✅ Doctor portal session managed without ir.config_parameter

🏗️ Architecture

✅ All major models inherit mail.thread + mail.activity.mixin (Chatter & Activities)
✅ Clinic name is a free Char field — supports any specialty without code changes
✅ Lab tests use One2many lines (health.lab.request.line) — fully dynamic

📊 Dashboard

✅ Today's appointments, patients, and revenue at a glance
✅ Total statistics: patients, bookings, revenue, pending invoices
✅ Low-stock medicine alerts

📅 Calendar & Kanban Views

✅ Calendar view for appointments (day / week / month)
✅ Kanban views for patients, appointments, and bookings

💊 Pharmacy Module

✅ Medicine catalogue with stock management
✅ Dispense orders with automatic stock deduction
✅ Low-stock alerts with configurable thresholds

💰 Invoicing

✅ Insurance payment method support
✅ Discount field on invoices
✅ Credit card payment option
✅ Printable invoice PDF report

🔬 Laboratory Requests

✅ Dynamic test lines — no more Boolean fields per test
✅ Master test catalogue (health.lab.test.type)
✅ State workflow: Draft → Sent → Partial → Done

🏥 Medical Records

✅ BMI auto-calculation from weight and height
✅ Structured vital signs: BP, HR, Temperature, O₂ Saturation, Weight, Height
✅ One-click Follow-Up booking creation from any record
